Projet

Simulateur de flux et gestion industrielle

Développement sous Ionic d'une application de gestion de crèche reliée à une API PHP, intégrant l'automatisation des suivis quotidiens pour les parents, l'adaptation aux assistantes maternelles et une déclinaison en marque blanche pour accélérer le déploiement client.

PHP Symfony Vue.js PostgreSQL

Contexte

Aqoona est une solution mobile moderne dédiée à la gestion de crèches et des structures de petite enfance. Cette application multi-rôles permet d'automatiser le suivi quotidien des enfants pour les parents, d'adapter l'ergonomie aux besoins spécifiques des crèches.

Missions & Réalisations

  • Développement Mobile & API

    Conception d'une application hybride sous le framework Ionic connectée à une API PHP robuste pour la gestion centralisée des données.

  • Automatisation des Rapports

    Mise en place d'un système de suivi quotidien automatisé et intuitif destiné aux parents pour renforcer le lien crèche-famille.

  • Marque Blanche & Ergonomie

    Déclinaison de l'application en marque blanche et adaptation des interfaces pour répondre aux usages spécifiques des crèches.

Fonctionnalités principales

Suivi quotidien automatisé

Génération et transmission simplifiée des rapports de la journée aux parents.

Interface assistantes maternelles

Parcours utilisateur optimisé et adapté aux contraintes du terrain.

Version marque blanche

Architecture modulable permettant la personnalisation visuelle pour chaque client.

API PHP & Synchronisation

Backend sécurisé pour la gestion des profils, des plannings et des données enfants.
